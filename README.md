# تانك TANK

تطبيق مراقبة مستوى مياه الخزان بواجهة عربية متوافقة مع الجوال، وسيرفر Python وقاعدة بيانات SQLite، مع حساس ESP32 فعلي.

## 1) تشغيل واجهة TANK والسيرفر
1. ثبّت Python 3.8 أو أحدث على الكمبيوتر.
2. افتح الطرفية داخل مجلد `tank` وشغّل `python server.py` (في ويندوز يمكن استخدام `py server.py`).
3. افتح `http://localhost:3000` من الكمبيوتر وأنشئ حسابًا.
4. من «حسابي ← ربط / تعديل الجهاز» اربط الجهاز بالمعرّف `TANK-0001`.
5. لمعرفة عنوان الكمبيوتر على الشبكة، استخدم عنوان IP الذي يطبعه السيرفر عند التشغيل. يجب أن يكون الكمبيوتر وESP32 متصلين بالراوتر نفسه.

## 2) توصيل ESP32 مع HC-SR04 واللمبات والبازر
| القطعة | طرف القطعة | طرف ESP32 |
|---|---|---|
| HC-SR04 | VCC | 5V/VIN حسب لوحة ESP32 ومصدرها |
| HC-SR04 | GND | GND |
| HC-SR04 | TRIG | GPIO 5 |
| HC-SR04 | ECHO | GPIO 18 عبر مقسّم جهد 5V إلى 3.3V |
| LED أخضر | موجب LED عبر مقاومة 220–330 أوم | GPIO 21 |
| LED أصفر | موجب LED عبر مقاومة 220–330 أوم | GPIO 22 |
| LED أحمر | موجب LED عبر مقاومة 220–330 أوم | GPIO 23 |
| اللمبات | سالب كل LED | GND |
| البازر الفعّال | موجب (+) | GPIO 19 |
| البازر الفعّال | سالب (-) | GND |

**مهم:** لا توصل ECHO مباشرة إلى ESP32؛ خرج HC-SR04 قد يكون 5V، بينما مدخل ESP32 يتحمل 3.3V فقط. استخدم مقسّم جهد مناسبًا، واجعل الأرضي GND مشتركًا. هذا الكود يفترض بازرًا فعّالًا Active Buzzer يعمل عند HIGH؛ إذا كان البازر يسحب تيارًا أكبر من قدرة GPIO، استخدم ترانزستور قيادة مناسبًا.

## 3) سلوك اللمبات والبازر
- **أكثر من 4 سم:** الأخضر يعمل، والأصفر والأحمر والبازر متوقفة.
- **من 2.5 إلى 4 سم شاملًا:** الأصفر يعمل والبازر يصدر صوتًا متقطعًا.
- **أقل من 2.5 سم:** الأحمر يعمل والبازر يصدر صوتًا مستمرًا.
- **قراءة غير صالحة:** تتوقف اللمبات والبازر حتى لا يصدر إنذار اعتمادًا على قراءة خاطئة.

هذه الحدود مطبّقة على المسافة المقاسة بين الحساس وسطح الماء. لذلك فإن انخفاض المسافة يعني أن سطح الماء أقرب إلى الحساس.

## 4) إعداد كود ESP32
افتح `esp32_sensor/esp32_sensor.ino` في Arduino IDE، ثم عدّل:
- `WIFI_SSID` و`WIFI_PASS`: اسم شبكة الراوتر وكلمة مرورها.
- `SERVER_URL`: عنوان IP للكمبيوتر الذي يشغّل السيرفر، مثل `http://192.168.1.50:3000/api/sensor/reading`.
- `DEVICE_ID` و`DEVICE_KEY`: يجب أن يطابقا القيمتين في `config.py`.

ارفع الكود إلى ESP32، وافتح Serial Monitor على سرعة `115200` للتأكد من قراءة المسافة وظهور عنوان IP ورد السيرفر. يجب أن يبقى الكمبيوتر مشغّلًا للسيرفر كي تستمر واجهة الويب في استقبال القراءات. اللمبات والبازر تعمل محليًا حتى لو انقطع اتصال السيرفر، ما دام ESP32 والحساس يعملان.

## 5) إعدادات الأمان
قبل الاستخدام الفعلي، غيّر `DEVICE_KEY` في `config.py` وفي كود ESP32 إلى مفتاح طويل وفريد، وغيّر `ADMIN_PASSWORD` الافتراضية في `config.py`. لا تفتح منفذ السيرفر على الإنترنت مباشرة.

## 6) اختبار الواجهة دون حساس
يمكن تشغيل `python simulate_sensor.py` في نافذة طرفية ثانية بعد تشغيل السيرفر لاختبار وصول القراءات الوهمية إلى الواجهة. أوقف المحاكي قبل اختبار ESP32 الحقيقي حتى لا تختلط القراءات.

## الملفات
- `server.py`: السيرفر وواجهات API.
- `schema.sql`: جداول قاعدة البيانات.
- `config.py`: إعدادات السيرفر والجهاز.
- `public/`: صفحات التطبيق وملفاته، مع الحفاظ على تصميم الواجهة الأصلية.
- `simulate_sensor.py`: محاكي قراءات للاختبار.
- `esp32_sensor/esp32_sensor.ino`: كود ESP32 + HC-SR04 + اللمبات الثلاث + البازر.
